Авто-подтяжка

Закладка содержит только маленький лоадер. При клике подтягивает свежий код с GitHub Pages.

Как это работает

  1. Перетащил кнопку в панель закладок (один раз).
  2. Открыл Facebook Ads Manager.
  3. Кликнул по закладке — лоадер делает fetch к harvertalex.github.io/metactrl-pro/bookmarklet.js и выполняет свежий код через Blob URL.
  4. При следующем git push на репозиторий — закладка автоматически берёт новую версию (через 10 минут кэша GitHub Pages, обходится ?t=Date.now() query-string).

Когда использовать обычную install-page

  • Когда нужна офлайн работа bookmarklet (без интернета не загрузится).
  • Когда не хочется зависеть от GitHub Pages uptime.
  • Когда нужна фиксированная версия которая не меняется.
