ACCOUNT OBJECT STRUCTURE
========================

From ACCOUNTS_CACHE (Autorules):
  {
    id: string (without 'act_' prefix),
    name: string,
    status: number (1=Active, 2=Limited, 101=Disabled, etc.),
    currency: string (e.g., 'USD'),
    conversionRate: number,
    ruleCount: number
  }

From pxState.accounts (Pixel Manager):
  {
    id: string,
    name: string,
    status: number,
    currency: string,
    label: string (computed display label)
  }

From ACCOUNTS (Launcher):
  {
    id: string,
    name: string,
    status: number,
    currency: string,
    bm: string (Business Manager name),
    label: string (computed display label)
  }

From OPS_ACCOUNTS_CACHE (Ops tab):
  {
    id: string,
    name: string,
    status: number,
    currency: string,
    label: string
  }

DISPLAY FORMATS
===============

Autorules (ACCOUNTS_CACHE):
  "● {name} ({id}) [{ruleCount}r] {currency}"
  Color based on status: Green (1), Red (2/101), Yellow (else)

Pixel Manager (pxState):
  "● {label}"
  Color based on status

Launcher:
  "{bm} · {label} {id}"
  With BM name shown separately

SEARCH/INDEX REQUIREMENTS FOR HELPER
====================================

For account search, need to index:
1. account.id (exact match or starts-with)
2. account.name (substring match, case-insensitive)
3. account.bm (substring match, case-insensitive) — launcher only

Recommendation: Simple substring search with case-insensitive matching.
Can optionally use fuzzy match for typo tolerance, but basic includes() sufficient.
